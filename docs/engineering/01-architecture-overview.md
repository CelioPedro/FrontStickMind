# 1. Architecture Overview

Stick Mind is a modern, interactive web application built without a heavy JS framework (Vanilla JS).
It relies on:
- **HTML5**: Semantic structure.
- **Vanilla CSS**: Custom properties for theming, CSS Grid/Flexbox for layout.
- **JavaScript (ES6)**: Modular approach using the Module Pattern (IIFE).
- **GSAP (GreenSock)**: Advanced scroll-driven animations and interpolations.
- **Three.js**: WebGL rendering for the interactive 3D particle head.

## Core Philosophy
The goal is to deliver a "Premium Feel" through smooth 60fps animations, glassmorphism, and seamless section transitions, ensuring desktop parity with optimized mobile degradation.
