# Stick Mind - 3D Particle Head

This is an advanced interactive WebGL component built using Three.js and GSAP.

It loads a 3D model (`head.obj`) using `OBJLoader`, interpolates the surface to create high-density particles, and applies custom shaders (Deep Purple Gradient + Backface Culling) to achieve a premium "Institutional UI" look.

## Credits
Based on the techniques used in the "threejs-particle-skull" repository by Anderson Mancini, combined with custom GSAP scroll-triggered animations.
